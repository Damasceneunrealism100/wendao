## ❓ What is wendao?

wendao is a high-performance tool that helps you search, organize, and link information. It acts like a smart map for knowledge. You can think of it as a way to build and explore connections between your notes or data. It uses AI to make this process faster and smarter. This software is useful if you work with lots of information and need to find links quickly.

## ▶️ How to Use wendao

1. **Open wendao**  
   Double-click the wendao icon on your desktop or find it in the Start menu.

2. **Create a new project**  
   On the main screen, click “New Project.” Give it a name that describes your information group.

3. **Add data and notes**  
   Import your documents or start typing notes. Wendao will automatically find connections.

4. **Explore the graph**  
   Use the visual graph view to see how your items link. Click nodes to expand information or add new links.

5. **Search and summarize**  
   Use the search bar to find items quickly. Wendao uses AI to give short summaries of your notes and data.

6. **Save your work**  
   The app saves automatically, but you can also export your project for backup or sharing.
